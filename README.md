🌍 Dishaara

Dishaara is a Python-based project that analyzes online information to identify possible tourist scam patterns in different cities.

It collects data from the web, checks for repeated scam-related claims, and shows risk trends instead of trusting single or emotional posts.

🔹 What Dishaara Does

Searches the web for tourist scam experiences

Collects text from articles, blogs, and forums

Detects scam-related claims

Identifies emotional language

Hides personal and business names

Distinguishes one-time incidents from repeated patterns

Provides simple risk confidence levels

🔹 Why Dishaara?

Tourists often depend on scattered reviews and posts.
Dishaara organizes this information into clear and useful safety insights.

🔹 Technologies Used

Python 3

Requests library

Basic text processing
